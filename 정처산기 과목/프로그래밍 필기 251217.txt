1. 운영체제의 개요

컴퓨터시스템의 자원을 효율적관리
사용자가 편리하고 효과적으로 사용할수잇는 환경제공


2. 운영체제의 목적

처리능력향상
반환시간 단축
사용가능도 향상
신뢰도 향상


3. 운영체제의 기능

프로세서 기억장치 입출력장치 파일 및 정보등의 자원관리
자원 스케줄링기능 제공
사용자와 시스템간의 인터페이스 제공
데이터를 관리, 데이터 및 자원의 ??


4. 운영체제 운용 기법

실시간 처리 시스템: 처리할 데이터가 생겨낼때마다 바로 처리함
분산 처리 시스템: 지역적으로 분산된 여러 컴퓨터를 합침
다중처리 시스템: 하나의 컴퓨터에 여러 CPU를 설치해 프로그램을 처리하는 방식
임베디드 시스템: 마이크로프로세서에 특정기능을 수행하는  응용프로그램을 탑재하여 컴퓨터의 기능을 수행하는 방식


5. 운영체제 운용기법 발달과정

1세대 일괄처리 시스템 -> 2세대 다중프로그래밍, 다중처리시스템, 시분할시스템, 실시간 처리시스템
-> 3세대 다중모드 -> 4세대 분산처리 시스템


6. 프로세스의 정의

PCB를 가진 프로그램
주 기억장치에 저장된 프로그램
프로세서가 할당되는 실체
프로시저가 활동중인 것
비동기적 행위를 일으키는 주체
지정된 결과를 얻기위한 일련의 계통적 동작

데이터베이스는
논리설계(erd)하고 만듬


속성: 데이터베이스를 구성하는 가장 작은 논리단위


도메인: 같은 타입의 원자값의 집합


릴레이션: 이런건 그림으로 보는게 좋음


후보키: 데이터를 식별하기위해 사용하는 속성들의 부분집합
기본키: 후보키 중 메인으로 하는 키


JOIN: 공통속성을 중심으로 두개의 릴레이션을 하나로 합치는거

합집합 교집합 차집합 교차곱 기호 검색해서 찾아보셈


정규화 과정: 비정규 릴레이션 -> 1NF(도메인이 원자값) -> 2NF(부분적 함수 종속 제거) -> 3NF(이행적 함수 종속 제거) ~~뒤에도 더잇는데 요즘은 잘 안씀

트랜잭션: ACID가 특성(원자성 일관성 독립성 영속성)
그래서 트랜잭션이 ㅜ머냐면 데이터베이스 insert하고 커밋/롤백할수잇는 개념?


View: 오라클에서 실제 테이블이 아니고 미리 뽑은 집합을 가상의 테이블로 만들고 거기서 뽑아갈수 잇게 한거


APM: 어플리케이션 퍼포먼스 매니지먼트. 다양한 모니터링 기능 지원
