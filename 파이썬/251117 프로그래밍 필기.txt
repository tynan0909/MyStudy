1-1. 파이썬이란?

네덜란드의 로썸이라는 사람이 개발한 인터프리터 언어
인터프리터 언어라는건 소스코드를 한줄씩 해석하고 그때그때 실행해 결과를 확인할수 잇는 언어라는뜻임
(like 자바스크립트)

파이썬 특: 
인간다운 언어	if 4 in [1, 2, 3, 4]: print("4가 있습니다") 라는 코드는 1234중에 4가 잇으면 괄호따옴표 안에 문장이 출력되는거임
문법이 쉬워 빠르게 배움
무료지만 강력함 - 오픈소스이고 복잡하거나반복연산이 많은것(시스템 프로그래밍, 하드웨어 제어)과는 안어울림, 대신 C랑 찰떡궁합임
간결함
개발속도가 빠르다

파이썬으로 무엇을 할 수 있을까?
웹 프로그래밍(django, FastAPI), 인공지능과 머신러닝(scikit-learn, TensorFlow, PyTorch, Keras), 수치 연산 프로그래밍(NumPy), 데이터 분석, 데이터베이스 프로그래밍, 시스템 유틸리티 제작하기, GUI프로그래밍, C/C++과 결합, 사물인터넷(Raspberry pi)

파이썬으로 할수 없는거
시스템과 밀접한 프로그래밍 영역, 모바일 프로그래밍
