매개변수(parameter)와 인수(arguments)
매개변수는 입력으로 전달된 값을 받는 변수
인수는 함수를 호출할 때 전달하는 입력값을 의미함
def add(a, b):	#a, b는 매개변수
	return a+b

print(add(3, 4))	#a, b는 인수

return은 함수를 돌리다가 상대방에게 주는거
def add(a, b)
	result = a+ b
	return result
는 a+b라는값을 돌려주는거임

def 함수이름(*매개변수):

(*매개변수)를 가변적이라고 해서 가변인자라고 한다

**kwargs 이건 키워드 매개변수임 딕서녀리를 받고싶을때 씀

가변변수(*a) 키워드변수 (**a) 이걸 같이 쓸수잇음
(name, *args, **kwargs): 이런느낌

키워드변수는 a=1이 사용댈때 {'a': 1}이라는 딕셔너리가 댐
