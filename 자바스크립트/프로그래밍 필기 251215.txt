Callbacks:	(함수를 전달)
Passing functions as arguments to other functions, such as event listeners or asynchronous operations.
비동기통신에서 다 처리하고나면 실행시키는 느낌
"I will call back later!" 가 모토


function myDisplayer(some) {
  document.getElementById("demo").innerHTML = some;
}

function myCalculator(num1, num2, myCallback) {
  let sum = num1 + num2;
  myCallback(sum);	//일을 다 하면 이걸 해라
}

myCalculator(5, 5, myDisplayer);
결과는 데모로 10의 값이 보내지고 HTML로 표시된다는거임
