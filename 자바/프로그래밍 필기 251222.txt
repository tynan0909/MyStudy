자바 기초 복습

	//정보
	int a;			<- 변수

	//생성자
	A(){}			<- A라는 인스턴스가 생성될 때 돌아가는 코드

	//처리
	void a(){}		<- void 너에게 리턴해줄게 없다

	
	void a(int a){}	<- 이 int(a)는 임시로 잇다가 사라지는 변수

만약 class B에서
new A(); 하면 A에 잇는 정보와 처리를 사용한다는거

	int b = 10;			<- 기본타입
	A a = new A();		<- 참조타입(new에서 가져옴
	a.a = 10; 			<- 이건 메소드 안에 잇어야함
	a.a(10);			<- 이건 a메소드가 int a에 넣을 매개변수로 10을 넣음

new를 써서 가져온걸 인스턴스 변수, 인스턴스 메소드라고 부른다
new를 쓰지 않고 가져올수 잇게 하는건 static
관례상 static 쓸때는 변수명을 대문자로 한다
	//클래스 변수
	static int A;			<-움직이지 않아서 정적이라고함

	//클래스 메소드
	static void a1(int a) {}	<- 메소드도 static붙일 수 있음. static붙은걸 클래스변수, 클래스 메소드라고 함

		A.A = 10;
		A.a1(10);		<- 이렇게 b클래스에서도 new없이 써먹을수 잇다

상속

public class C {
	int c;
	void c(){}
	
}
public class D {
	C c = new C();
	void d() {
		c.c = 10;
		c.c();
	}
}
원래는 이렇게 하는건데(D has C)
public class D extends C{
	void d() {
		c = 10;
		c();
	}
}
이렇게 바로 쓸수잇다(D is C)


상속 - 오버라이딩

	void c() {
		c = 20;
	}
이제 void c안에서 c는 20이라고 재정의
D is C인데 D를 요청햇을때 C도 들어온다
즉 extends C는 new C도 포함된거
public class DTester{
	public static void main(String[] args) {
		D d = new D();
	}
}
여기서 D만 불러도 C도 온다는거, C c = new D();도 된다는거 D = C니까
그후 c.c(); 하면 c로 받앗지만 실제로 작동하는건 D의 c메소드임
만약 부모껄 쓰고싶으면 
		C c1 = new C();
		c1.c();


추상클래스

추상메소드를 하나이상 가진 클래스
클래스와 메소드 앞에 abstract를 붙여야함
추상클래스에 그냥 메소드를 넣어도 되긴함
추상클래스의 목적은 클래스 설계이고, new를 쓸수 없다(상속받아서 쓰란거)
public abstract class E {
	abstract void e();
	void e1() {};
}
public class F extends E{
	void e() {}
}이런식
즉 추상클래스에서 이런 이름의 기능이 필요하니까
밑에서 완성시켜달라는거(추상메소드를 구체화해라)


상속을 염두에 두지 않는 추상클래스 => 인터페이스

인터페이스는 abstract 쓰지 않고 그냥 써도 추상메소드임
상속도 구현도 목적이 아니라 그냥 설계임
인터페이스에서 설계한걸 받으려면 클래스이름 뒤에 implements 인터페이스이름 하면댐
근데 그냥 void g(){}하면 오류뜸 구현할때 앞에 public 붙여야함
대충 public class H implements G 라고 대잇으면 클래스H는 G기능을 구현햇다고 보면댐

상속과의 차이점은 단일상속이 아니라 여러가지로 뻗을수잇음
public interface J extends G, I 이렇게 하면 
public class H implements J{
	public void g() {}
}이렇게 하나로 묶을수도 잇음
public class H extends E implements J 이렇게 상속하면서 implements도 할수잇음

JVM(Java Virtual Machine)

java 바이트코드를 실행하는 가상머신
메모리할당과 회수가 자동화 되어잇음
구조는 
클래스로더: class 파일을 로딩하고 링크하여 런타임 데이터 영역에 배치 
런타임데이터영역: 메소드에리어 힙에리어 스택에리어가 잇다. new할때는 힙에 인스턴스변수가, 메소드는 메소드, 스택은 로컬변수가 쌓이는곳
실행엔진: 바이트코드를 실제로 실행하는 부분, Just In Time 컴파일러를 포함
JIT 컴파일러는 자주 사용되는 코드를 네이티브코드(C코드)로 컴파일 하여 성능을 최적화하고
가비지 컬렉터는 자동으로 메모리 정리
