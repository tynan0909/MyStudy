WSL이란? Windows Subsystem for Linux
즉 리눅스용 윈도우 하위시스템
가상머신또는 이중부팅 없이 윈도우에서 리눅스를 쓸수 잇는 기능
파워섈에서 wsl --install 쓰면 댐

☆는 자주쓰는거
/root 최상위 디렉토리
/bin 기본 명령어	bin -> usr/bin는 바로가기임
/boot 부팅에 필요한거
/dev device의 약자. 하드웨어장치를 나타내는 파일
☆/etc 시스템 설정파일이 모인곳. 네트워크설정, 사용자계정정보, 프로그램설정파일 등
☆/home 일반사용자들의 개인 디렉토리의 위치. 각 사용자는 /home/사용자명 형태의 디렉토리를 갖게됨
/lib 시스템과 프로그램 실행에 필요한 공유라이브러리파일이 저장되는곳
/mnt 파일시스템을 임시로 마운팅할떄 사용
/opt 추가로 설치하는 
/tmp 임시파일이 저장되는 곳
☆/usr 사용자프로그램과 데이터가 저장되는곳. 애플리케이션, 라이브러리, 문서등이 잇음
☆/var 로그파일, 캐시, 메일 등 자주 변하는 데이터 저장

======명령어=====

pwd: 현재 디렉토리 확인

ls: 현재 디렉토리의 리스트

cd ~: 내 홈 디렉토리(로그인한사람)로 이동

ls -al: 
첫 번째 문자	파일 유형	-는 일반 파일, d는 디렉토리(폴더)
파일 권한	읽기/쓰기/실행	rwxr-xr-x (소유자/그룹/기타 사용자 권한)
링크 수	연결된 수	해당 파일이나 디렉토리에 연결된 하드 링크 수
소유자/그룹	관리 정보	파일을 만든 사용자와 해당 사용자가 속한 그룹
파일 크기	용량	바이트(Byte) 단위의 파일 크기
수정 시간	최근 변경일	파일이 마지막으로 수정된 날짜와 시간
파일 이름	이름	파일이나 디렉토리의 실제 이름

whoami: 내가 누구냐

whatis (명령어): 명령어에 대한 설명 

mkdir (원하는이름): 디렉토리 만들기

man mkdir: make directories의 약자, 문서모드로 변환, 

chmod (숫자) (디렉토리이름): 권한 변경

cd /(위치): 이동
cd ../, cd ./: 상대위치 이동
주의할점은 왠만하면 ./, ../ 같은거 붙여줘야함. 왜냐면 다른곳에 잇는 동명이인에게 갈수 잇기때문에

ls -l *.txt: .txt로 끝나는 파일 찾아줘

rm (파일이름): 삭제	rm -rf는 강제삭제니까 완전조심해야댐

cat (파일이름): 파일 내용을 화면에 출력

vi (파일이름):  파일편집(문서모드), 탈출법은 :wq!임 -> i(insert), a(add), o(open),

/(검색할 문자열): 오른쪽 아래방향으로 문자열 검색
?(검색할 문자열): 왼쪽 위방향으로 문자열 검색
:set nu: 행번호 표시
(숫자)G: 원하는 행으로 이동
H: 맨위로 이동
G: 맨아래로 이동
dd: 1줄지우기
dG: 현재부터 끝까지 지우기
